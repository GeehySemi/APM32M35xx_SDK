# APM32M35xx_SDK
Official software development kit for Geehy APM32M3514 microcontrollers.

## Current version

- SDK version: V1.0.0
- Supported device: APM32M3514
- Official package date: May 30th, 2024
- Release notes date: October 30th, 2026
- Official download: [APM32M35xx_SDK_V1.0.0.zip](https://www.geehy.com/uploads/tool/APM32M35xx_SDK_V1.0.0.zip)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
