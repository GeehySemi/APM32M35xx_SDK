&par Example Description

This example describes how to use the ADC to convert VREF voltage
applied to the ADC Channel 17.
The converted voltage is displayed on serial assistant through USART1.

The USART1 is configured as follows:
    - TX:PA9, RX:PA10
    - BaudRate = 115200 baud
    - Word Length = 8 Bits
    - One Stop Bit
    - No parity
    - Hardware flow control disabled (RTS and CTS signals)
    - Receive and transmit enabled

&par Hardware Description
    - Close J2 and J3
    - Close J6 and J8

&par Directory contents

  - ADC/ADC_VREF/Source/apm32m35xx_int.c          Interrupt handlers
  - ADC/ADC_VREF/Source/main.c                   Main program

&par IDE environment

  - MDK-ARM V5.36
  - EWARM V8.50.5.26295
  - ECLIPSE V4.24

&par Hardware and Software environment

  - This example runs on APM32M35XX MINI Devices.
