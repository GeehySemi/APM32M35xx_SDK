&par Example Description

This example shows how to synchronize TMR peripherals in cascade mode, two timers
TIM1 and TIM3 are used.

The phenomenon of observe whether the output waveform is correct through
the oscilloscope.

using TMR3 CH1(PA6) to output PWM
using TMR1 CH1(PA8) to output PWM

&par Directory contents

  - TMR/TMR_SynchronizationWithTMR1/apm32m35xx_int.c     Interrupt handlers
  - TMR/TMR_SynchronizationWithTMR1/Source/main.c              Main program

&par IDE environment

  - MDK-ARM V5.36
  - EWARM V8.50.5.26295
  - ECLIPSE V4.24

&par Hardware and Software environment

  - This example runs on APM32M35XX MINI Devices.
